# Res Bot Privacy Policy

**Last updated: 15 November 2026**

This policy explains what information Res Bot ("the bot", "we") collects, why, and what you can do about it. Res Bot is a Discord bot run by the Res Hood team for the Res Hood Discord server and the Res Hood Roblox game.

By using a server where Res Bot is installed, or by using its commands, you agree to this policy.

## 1. What we collect

Res Bot only stores what it needs to work. All of it is stored in a private database on the computer that runs the bot.

| What | When | Why |
| --- | --- | --- |
| **Your Discord user ID and username** | When you use a command, open a ticket, join or leave, get moderated, verify, or make dashboard changes | To show who did what, and to run the feature you used |
| **Moderation cases** (who was moderated, by whom, the reason, duration and time) | When staff use `/ban`, `/kick`, `/timeout`, `/warn` and similar, or the in-game panel | To keep a moderation history for staff |
| **Tickets** (ticket channel, who opened, claimed and closed it, and when) | When you open a ticket | To run the ticket system |
| **Ticket transcripts** (the messages, usernames and attachment links in a ticket) | When a ticket is closed | Saved as a file in a private staff channel so staff can review support cases |
| **Invite info** (who invited you, which invite code, when you joined) | When you join the server | For the invite tracker |
| **Temporary voice channels** (channel and owner) | When you use Join to Create | To delete the channel when it is empty |
| **Roblox account link** (your Discord ID, Roblox user ID and Roblox username) | When you verify | To give you roles that match your Roblox group rank |
| **Verification code** | While you verify | Deleted after you verify, or after 15 minutes |
| **Game stats** (Roblox user ID, username, win streaks, wins, losses, tryout results, tester notes, in-game star status) | When the Res Hood game sends them | For leaderboards and tryout results |
| **In-game moderation and command logs** (who did what in the game, to whom, and why) | When it happens in the game | So staff can see in-game actions in Discord |
| **Embed templates** (the template content and who saved it) | When staff save a template | So staff can reuse messages |
| **Server settings and an audit log of dashboard changes** | When staff change settings | So staff know who changed what, and when |

### What we do **not** collect

- We do **not** read or store your normal chat messages. The only message text the bot saves is inside **ticket channels**, when a ticket is closed.
- We do **not** collect passwords, emails, payment details, IP addresses of Discord users, or your location.
- We do **not** use analytics, trackers or ads.

## 2. Information posted in server channels

Some features post information into private staff channels picked by the server owner. These include join and leave logs (with account age and roles), invite logs, boost logs, command logs, moderation logs and ticket transcripts. These posts are stored by **Discord**, not by us, and follow [Discord's Privacy Policy](https://discord.com/privacy).

The bot may also send you a **direct message** when staff moderate you (for example, the reason you were banned or timed out).

If someone sends the bot's game connection a request that gets rejected, the network address it came from may be posted in a private staff security channel, to help stop abuse.

## 3. Who we share it with

We never sell or rent your information. We only share it with the services the bot needs to work:

- **Discord** shows and stores the bot's messages. [Discord Privacy Policy](https://discord.com/privacy)
- **Roblox** is asked for public profile info (username, display name, avatar, join date, group rank) when someone looks up a player or verifies. It also receives game bans, unbans and kicks that staff send from Discord. [Roblox Privacy Policy](https://en.help.roblox.com/hc/articles/115004630823)
- **Cloudflare** carries the encrypted connection between the Roblox game and the bot. [Cloudflare Privacy Policy](https://www.cloudflare.com/privacypolicy/)

Server staff (Owner, Admins, Moderators) can see moderation history, tickets, transcripts and logs, so they can run the server.

## 4. How long we keep it

- **Verification codes:** 15 minutes at most.
- **Game connection security codes:** about 10 minutes.
- **Roblox profile lookups:** kept in memory for up to 30 minutes, never saved.
- **Everything else** (moderation cases, Roblox links, tickets, invite info, stats, templates, settings) is kept until it is removed, or until the bot is taken out of the server.
- **Backups** of the database are made daily, and the newest 14 are kept. Deleted data disappears from backups within about 14 days.

## 5. Your choices and rights

- **Unlink Roblox:** run `/roblox unlink` at any time. Your link is deleted and your verified roles are removed.
- **See or delete your data:** ask the Res Hood staff (see "Contact" below). We will tell you what we have about you, and delete it unless we need to keep a moderation record to protect the server.
- **Leave:** you can leave the server at any time. We keep moderation records for safety, but you can ask us to delete other data.

## 6. Security

The database stays on the bot's own computer and is not public. The connection from the Roblox game is encrypted (HTTPS) and every request must carry a secret signature. Only server staff can use staff features. No system is perfectly secure, but we keep what we store to a minimum.

## 7. Children

You must meet [Discord's minimum age](https://discord.com/terms) (13 in most countries) to use Discord, and therefore the bot. We do not knowingly collect extra information about children. If you think a child's data should be removed, contact us.

## 8. Changes

We may update this policy. When we do, we change the "Last updated" date at the top. Big changes are announced in the Res Hood Discord server.

## 9. Contact

Questions or data requests: open a ticket in the **Res Hood Discord server**, or [open an issue on this page's GitHub repository](../../issues).
